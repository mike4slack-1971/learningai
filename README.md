# learningai

Personal sandbox for learning AI tools, GitHub, and Cursor.

This repo is a place to try things, leave notes, and practice the everyday workflow: edit → commit → push.

## Purpose

- Learn how Git and GitHub fit into day-to-day work
- Experiment with Cursor and AI-assisted coding
- Keep small, throwaway experiments in one place

## Getting started

```bash
git clone https://github.com/mike4slack-1971/learningai.git
cd learningai
```

Then open the folder in Cursor and start exploring.
